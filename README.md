# Semiconductor-Recruiter-Technical-Glossary

# Chip Design Fundamentals
1. RTL (Register Transfer Level)
The stage where engineers write chip logic using hardware languages like Verilog.
2. ASIC (Application-Specific Integrated Circuit)
A custom chip designed for a specific function (e.g., AI accelerator).
3. SoC (System on Chip)
A complete computer system on a single chip (CPU + GPU + memory + networking).
4. IP Core
Reusable chip building blocks (e.g., USB controller, memory controller).
5. Microarchitecture
The internal design structure of a CPU or chip.
Hardware Design Languages
6. Verilog
A hardware programming language used to design digital circuits.
7. SystemVerilog
An advanced version of Verilog used for design and verification.
8. VHDL
Another hardware design language used in chip development.
Chip Design Roles
9. RTL Design Engineer
Designs the digital logic of chips.
10. Physical Design Engineer
Transforms RTL logic into physical chip layout.
11. Verification Engineer
Tests the chip design before manufacturing.
12. DFT Engineer (Design for Test)
Designs features to test chips after manufacturing.
Verification & Testing
13. UVM (Universal Verification Methodology)
A framework used to verify complex chip designs.
14. Testbench
A simulation environment used to test chip functionality.
15. Functional Verification
Testing if the chip works according to the design.
16. Coverage
Measurement of how much of the chip design has been tested.
# Semiconductor Manufacturing
21. Wafer
A thin slice of silicon used to manufacture chips.
22. Lithography
The process of printing chip circuits onto silicon wafers.
23. Fabrication (Fab)
The factory where semiconductor chips are manufactured.
24. Node (Process Node)
Technology generation of chip manufacturing (e.g., 5nm, 3nm).
# Advanced Semiconductor Concepts
29. GPU (Graphics Processing Unit)
A chip designed for parallel processing.
Example company: NVIDIA.
30. CPU (Central Processing Unit)
Main processor of a computer.
Example companies:
•	Intel
•	AMD
# AI Hardware Terms
38. AI Accelerator
Specialized chip designed for AI workloads.
Example companies:
•	Cerebras Systems
•	Graphcore
39. Tensor Core
Specialized hardware for AI matrix calculations.

# Semiconductor Tools
44. Cadence
EDA software used for chip design.
45. Synopsys
Another major semiconductor design tool provider.
46. Mentor Graphics
EDA tools for verification and testing.

# Semiconductor Ecosystem
47. Foundry
Company that manufactures chips for others.
Example: TSMC.
48. Fabless Company
Designs chips but outsources manufacturing.
Examples:
•	NVIDIA
•	Qualcomm
49. IDM (Integrated Device Manufacturer)
Company that designs and manufactures chips.
Example:
•	Intel
50. OSAT
Outsourced semiconductor assembly and test companies.
Example:
•	Amkor Technology
